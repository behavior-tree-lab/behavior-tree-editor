# 自定义节点

内置节点覆盖了通用的控制流，但你的智能体还需要领域相关的**动作**和**条件** —— 比如 `MoveTo`、`IsHungry`、`Attack` 等。编辑器允许你把这些定义为自定义节点类型。

## 创建节点类型

1. 在节点面板中，选择节点所属的类别 —— **组合**、**装饰**、**动作** 或 **条件**。
2. 新增一个节点类型并给它一个**名称（name）**（这是导出到 JSON 时的标识符，也是你的运行时库匹配的依据）。
3. 设置一个**标题（title）**（画布上显示的标签）和可选的**描述（description）**。
4. 定义节点所需的**属性（properties）** —— 这些会成为每个实例上可编辑的字段。

## 属性

属性是附加在节点类型上的键值对。常见用途：

- `MoveTo` 动作可能暴露一个 `target` 属性。
- `Wait` 装饰节点可能暴露一个 `duration` 属性。

画布上每个节点实例都可以单独覆盖这些值，因此同一个节点类型可以用不同参数复用。

## 把节点对应到代码

节点的**名称（name）**是编辑器与运行时之间的契约。导出为 JSON 时，每个节点都携带它的 `name`；你的行为树运行时会查找以同样名称注册的类，并用该节点的属性来实例化它。

请保持名称稳定 —— 在编辑器中重命名节点类型，意味着你需要同步更新代码中对应的类注册。
